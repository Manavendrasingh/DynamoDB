## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ npm install
```

## User REST API with DynamoDB

Set these environment variables before running the app:

```bash
export AWS_REGION=us-east-1
export USERS_TABLE_NAME=Users
```

Create a DynamoDB table named `Users` with `id` as the partition key.

Available endpoints:

```bash
# create user
curl -X POST http://localhost:3000/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Jane Doe","email":"jane@example.com","phone":"1234567890","address":"New York"}'

# get all users
curl http://localhost:3000/users

# get one user
curl http://localhost:3000/users/<id>

# update user
curl -X PATCH http://localhost:3000/users/<id> \
  -H "Content-Type: application/json" \
  -d '{"phone":"9999999999"}'

# delete user
curl -X DELETE http://localhost:3000/users/<id>
```

## AWS deployment

This project includes:

- `Dockerfile` for building the NestJS API container
- `infrastructure/cloudformation.yml` for ECS Fargate, ALB, DynamoDB, CloudWatch Logs, and IAM roles
- `../.circleci/config.yml` for CI/CD from CircleCI

Add these environment variables in CircleCI:

```bash
AWS_ACCESS_KEY_ID=<your-access-key>
AWS_SECRET_ACCESS_KEY=<your-secret-key>
AWS_REGION=us-east-1
VPC_ID=vpc-xxxxxxxx
PUBLIC_SUBNET_IDS=subnet-xxxxxxxx,subnet-yyyyyyyy
```

Optional CircleCI variables:

```bash
PROJECT_NAME=dynamo-db-api
ENVIRONMENT_NAME=dev
ECR_REPOSITORY_NAME=dynamo-db-api
STACK_NAME=dynamo-db-api-dev
USERS_TABLE_NAME=Users
```

The CircleCI workflow runs on the `main` branch. It creates the ECR repository if missing, pushes the Docker image, and deploys the CloudFormation stack.

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
